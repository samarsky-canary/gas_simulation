# Структура работы для текущей ML-only версии

## 1. Анализ предметной области и существующих подходов

1.1. Особенности эксплуатации ГРС/ПРГ.

1.2. Газовый фильтр как объект диагностирования.

1.3. Процесс технического обслуживания фильтров.

AS-IS:

```text
датчики -> SCADA -> пороги -> оператор -> ППР/аварийное ТО
```

TO-BE:

```text
датчики/симулятор -> признаки -> ML-прогноз RUL -> правила -> рекомендация ТО
```

1.4. Нормативная и регламентная основа обслуживания.

1.5. Входные параметры оценки состояния фильтра: `P_in`, `P_out`, `deltaP`, `Q`, `T`, timestamp, история ТО, паспортные данные.

1.6. Анализ методов предиктивного обслуживания: пороговые методы, статистические методы, физико-математические модели, классическое ML, гибридные методы, explainable AI.

1.7. Ограничения существующих подходов: шум и пропуски данных, влияние расхода на перепад давления, редкость отказов, невозможность прямого наблюдения уровня засорения, недостаточная интерпретируемость чисто ML-подходов.

1.8. Постановка задачи исследования: разработать симулятор, feature builder, ML baseline, аналитический RUL, rule-based слой и объяснимую рекомендацию по ТО.
