# 3.7. Аналитическая оценка остаточного ресурса

В текущей версии отдельный пороговый baseline удален из программного контура.
Аналитическая часть используется как физически интерпретируемая оценка RUL и как
fallback для гибридного слоя.

## Назначение аналитического RUL

Аналитическая оценка отвечает на вопрос: сколько часов осталось до достижения
критического нормированного перепада давления при текущей модели засорения.

Она используется:

- как независимый baseline для сравнения с ML-прогнозом;
- как fallback при плохом качестве данных;
- как один из входов гибридного RUL fusion;
- как отдельный ряд на графике сравнения RUL.

## Связь с ML

ML-модель не получает `RUL_analytic_h` как входной признак. Она напрямую прогнозирует
`RUL_oracle_h` по наблюдаемой телеметрии и производным признакам. Это позволяет
сравнивать ML и аналитику как два независимых подхода.

Гибридный слой затем выбирает итоговый `RUL_fused_h` с учетом качества данных,
согласованности прогнозов и доверия к ML.

## События обслуживания

Рекомендации обслуживания больше не формируются отдельным пороговым слоем. UI
рассчитывает плановое и срочное обслуживание по устойчивому пересечению RUL-порогов
для ML, аналитического и гибридного рядов.
