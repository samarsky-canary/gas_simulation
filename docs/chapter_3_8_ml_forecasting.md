# 3.8. Реализация ML-прогнозирования

ML-прогнозирование реализовано как baseline-модель для оценки остаточного ресурса фильтра. В качестве модели используется `RandomForestRegressor`: ансамбль деревьев решений, который хорошо подходит для табличных признаков, не требует сложной нормализации входов и позволяет быстро получить интерпретируемый ориентир качества. В данной работе RandomForest не заменяет физическую и rule-based логику, а служит независимой ML-оценкой RUL.

Целевая переменная модели - `RUL_oracle_h`, то есть эталонный остаточный ресурс, доступный в синтетических данных симулятора. На вход подаются только наблюдаемые параметры и инженерные признаки: давления, перепад, расход, температура, нормированный перепад, скользящие статистики, тренд, доля пропусков и время выше warning-порога. Скрытые поля вроде `clog_level`, `state` и сам target не используются как входы, чтобы избежать утечки ответа.

Разделение на train/test выполняется без случайного перемешивания соседних временных точек. Если в данных есть несколько независимых `run_id`, тестовая часть выделяется целыми прогонами, чтобы модель проверялась на другом сценарном ряду. Если прогон один, используется временной split: первые 70% строк идут на обучение, последние 30% - на тест. После обучения сохраняются модель `random_forest_rul.joblib`, таблица предсказаний, JSON с метриками и Markdown-отчет. Качество оценивается метриками MAE, RMSE и R2.

| Функция | Назначение |
|---|---|
| `train_and_export_ml_baseline(dataset, output_dir, features=None, test_run_ids=None)` | Основная функция ML-модуля. Объединяет датасет с инженерными признаками, готовит данные, выполняет train/test split, обучает `RandomForestRegressor`, строит предсказания и сохраняет модель, метрики, отчет и таблицы прогнозов. |
| `_attach_features(dataset, features)` | Добавляет к каноническому датасету инженерные признаки feature builder. Объединение выполняется по `timestamp`, а при наличии нескольких прогонов - по `run_id` и `timestamp`. |
| `_prepare_dataset(dataset)` | Сортирует данные по времени и `run_id`, приводит `timestamp` к datetime, заполняет пропуски во входных признаках методом forward/backward fill и удаляет строки, где ML-входы остались неполными. |
| `_split_mask(data, train_share, test_run_ids=None)` | Выбирает стратегию разделения на train/test. Для корпуса из нескольких `run_id` вызывает split по прогонам, для одного временного ряда использует упорядоченный split по времени. |
| `_run_id_split_mask(data, train_share, test_run_ids=None)` | Делит данные по целым независимым прогонам. Это снижает риск переоценки качества, потому что соседние точки одного и того же временного ряда не попадают одновременно в train и test. |
| `_time_split_mask(data, train_share)` | Делит один временной ряд без перемешивания: начальная часть используется для обучения, последующая - для тестирования. Такой подход не подмешивает будущие точки в обучающую выборку. |
| `_train_rul_regressor(data, train_mask)` | Обучает `RandomForestRegressor` предсказывать `RUL_oracle_h` по колонкам `ML_INPUT_COLUMNS`. После обучения считает предсказания на test-части и формирует метрики качества. |
| `_regression_metrics(y_true, y_pred)` | Считает основные метрики регрессии: `MAE` в часах, `RMSE` в часах и `R2`. Для маленьких выборок безопасно возвращает `None` там, где метрика не может быть корректно рассчитана. |
| `_regression_group_metrics(test, y_pred, target, group_column)` | Считает метрики отдельно по группам, например по `run_id` или `scenario`. Используется для анализа качества модели на разных сценариях. |
| `_build_predictions(data, train_mask, regressor)` | Формирует итоговую таблицу ML-прогнозов с колонками `run_id`, `timestamp`, `filter_id`, `scenario`, `split`, `RUL_oracle_h` и `RUL_pred_h`. |
| `_report_markdown(metrics)` | Генерирует Markdown-отчет по ML baseline: входные признаки, тип split, размеры train/test и метрики RUL-регрессии. |
| `_regression_markdown_rows(rows, key)` | Форматирует групповые метрики для Markdown-отчета, например метрики по сценариям. |
| `_fmt_metric(value)` | Приводит числовую метрику к компактному текстовому виду или возвращает `н/д`, если значение отсутствует. |
